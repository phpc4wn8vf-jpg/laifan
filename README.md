## 如何新增一张证书

1. 把图片放进 `assets/certs/`（建议宽度 ≤ 1600px、大小 ≤ 400KB）
2. 在 `index.html` 里给对应的荣誉条目加一个按钮：

```html
<button class="cert-btn" type="button" data-cert="assets/certs/文件名.jpg" data-cert-title="证书标题">
  <svg viewBox="0 0 24 24" aria-hidden="true"><path d="M5 8.5h14v10H5z"/><path d="m5.4 9 6.6 4.6L18.6 9"/></svg>
  查看证书
</button>
```

凡是带 `data-cert` 的按钮都会被自动收进灯箱画廊，按页面顺序左右翻页，无需改 JavaScript。

## 常用修改位置

- 改文字：编辑 `index.html`，中文内容都在标签之间。
- 改配色：`styles.css` 顶部 `:root` 的 `--accent`、`--bg` 等变量全局生效；浅色主题在 `html[data-theme="light"]`。
- 改首屏打字文字：`script.js` 里的 `phrases` 数组。
- 改荣誉分类：`index.html` 中每条 `li.honor` 的 `data-cat`（竞赛 / 奖学金 / 荣誉）。

## 部署与更新

2. 用 GitHub API 批量上传（需要一个含 `repo` 权限的 Personal access token，用后请立即吊销）。
