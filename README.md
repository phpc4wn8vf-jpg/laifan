# 赖帆 · 个人主页

一个纯静态的个人网站，内容依据简历《赖帆.pdf》整理。
**零依赖**：没有框架、没有 CDN、没有外部字体，双击 `index.html` 即可在浏览器打开，断网也能正常显示。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构（首屏、关于、教育、荣誉、科研、经历、联系） |
| `styles.css` | 全部样式：深色/浅色主题、响应式布局、动效 |
| `script.js` | 交互：主题切换、滚动进度、打字机、荣誉筛选、数字动画、复制邮箱 |

## 常用修改位置

- 改文字：直接编辑 `index.html`，中文内容都在标签之间。
- 改配色：编辑 `styles.css` 顶部 `:root` 里的 `--accent`、`--accent-2`、`--bg` 等变量即可全局生效；
  浅色主题的变量在 `html[data-theme="light"]` 里。
- 改首屏打字文字：`script.js` 里 `phrases` 数组。
- 荣誉筛选的分类：`index.html` 中每条 `li.honor` 的 `data-cat` 属性（竞赛 / 奖学金 / 荣誉）。

## 想加头像 / 照片

当前首屏用的是姓名首字（「赖」）做的渐变色块头像，不依赖图片文件。
若要换成真人照片：把照片命名为 `avatar.jpg` 放到本目录，然后在 `index.html` 里把

```html
<div class="avatar" aria-hidden="true"><span>赖</span><i class="ring"></i></div>
```

替换为

```html
<div class="avatar"><img src="avatar.jpg" alt="赖帆" /><i class="ring"></i></div>
```

并在 `styles.css` 中补一条 `.avatar img { width: 96px; height: 96px; border-radius: 50%; object-fit: cover; }`。

## 部署到公网（任选其一）

1. **GitHub Pages**：新建仓库 → 上传这三个文件 → Settings → Pages → Source 选 `main` 分支根目录 → 得到 `https://用户名.github.io/仓库名/`。
2. **Netlify / Vercel**：把整个文件夹拖进部署页面即可，无需构建命令。
3. **国内访问（可选）**：Gitee Pages、阿里云 OSS 静态网站托管等。
